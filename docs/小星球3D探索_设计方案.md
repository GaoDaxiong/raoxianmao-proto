# 小星球 3D 探索 · 设计方案（feature/little-prince-3d）

> 面向：高大雄 · 本文件为 feature/little-prince-3d 分支的设计说明，**尚未改动玩法代码**。实施前需确认第 4 节技术路线。

## 1. 目标与参考

- 参考 Sac《小王子：星辰之旅》littleprince.dev：3D 故事书质感、黄金时刻体积光、粉彩天空、慢镜头、安静略惆怅。
- 保留本项目核心诡计：玩家路径悄悄拼成字母；玩时看不出；通关后镜头拉开轨迹亮成字。默认词仍 I❤U，可分享自定义。
- 主角仍是「团绒」（烟灰白毛球 + 浅蓝耳尖，大垂耳可滑翔），不要抄小王子造型/围巾/金发男孩。

## 2. 玩法形态（相对 v6.1 横版的变化）

- 从 2D 侧视平台跳，改为可绕行的**小星球 / 浮岛** 3D 第三人称漫步。
- 一关 ≈ 一颗小星球（或一串相连浮岛）。字母笔画 = 球面上的路径：竖笔可沿经线爬坡/顺着气流升，弧线绕赤道山谷，提笔用传送门/星桥。
- 镜头：跟在角色斜后方，略远、略慢；终点揭晓时拉到俯视/远景，整条足迹连成字母浮在星球表面或星空中。
- 手感仍要对标原神式摇杆：左浮动摇杆、右跳/滑翔/当前耳朵能力；推即走、松即停。

## 3. 能力 / 机关 / 敌人 / Boss（从 v6 迁移到球面）

- 五种耳朵：铃耳、伞耳、钻耳、弹耳、灯耳 — 行为语义不变，表现改为球面上的交互。
- 假岔路：看起来能走的小径，逆风/环流把你吹回主路径。
- 隐藏房间：星球背面或云下小洞。
- Boss：大雾怪占住字母最后一笔对应的山顶，摇铃散雾。
- 首关仍做 U：五段主题（森林丘、萤光洞、泉水庭、风车脊、云顶 Boss）环绕在同一颗「U 形峡谷」星球上。

## 4. 技术路线（建议，需用户确认后才实施）

- 原型阶段优先 **Three.js / WebGL 的 H5**，继续 GitHub Pages + 微信小游戏 H5 壳，便于沿用现有分享 `#c=`。
- 若后期要正式微信原生 3D，再评估团结引擎 / Unity；当前分支先不要切 Unity。
- 资产：概念图（ChatGPT）→ 低模/程序化星球 + 简单 PBR → 逐步替换。黄金时刻用定向光+天空盒+轻雾+bloom。
- 性能目标：中端手机 30fps+，星球半径控制、远景用 billboard。

## 5. 迭代版本

- **v0 概念**：方案 + 概念图（当前）。
- **v1 可走原型**：单星球、团绒可走跳滑翔、足迹记录、假终点不揭晓字母。
- **v2 U 关完整**：五区能力、机关、Boss、揭晓 U、分享。
- **v3 字母池**：I/L 等，分享链接真正驱动多字母。
- **更远**：10 玩法池、完整 26 字母、微信正式包。

## 6. 明确不做（本分支前期）

- 不合并回 main，直到用户验收可玩原型。
- 不改 v6.1 线上默认页；可用 `?v=planet-0` 或子路径预览。
- 不复制小王子 IP 角色与剧情文案。
