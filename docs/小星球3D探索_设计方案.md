# 小星球 3D 探索 · 设计方案（feature/little-prince-3d）

> 面向：高大雄 · 本文件为 feature/little-prince-3d 分支的设计说明。第 4 节技术路线已按用户决定改为 **Unity 6 / 团结引擎**，**本 GitHub Pages 仓库不放可玩 3D 原型**。对照表见 [技术栈对照_Sac.md](技术栈对照_Sac.md)。

## 1. 目标与参考

- 参考 Sac《小王子：星辰之旅》littleprince.dev：3D 故事书质感、黄金时刻体积光、粉彩天空、慢镜头、安静略惆怅。
- 保留本项目核心诡计：玩家路径悄悄拼成字母；玩时看不出；通关后镜头拉开轨迹亮成字。默认词仍 I❤U，可分享自定义。
- 主角仍是「团绒」（烟灰白毛球 + 浅蓝耳尖，大垂耳可滑翔），不要抄小王子造型/围巾/金发男孩。

## 2. 玩法形态（相对 v6.1 横版的变化）

- 从 2D 侧视平台跳，改为可绕行的**小星球 / 浮岛** 3D 第三人称漫步。
- 一关 ≈ 一颗小星球（或一串相连浮岛）。字母笔画 = 球面上的路径：竖笔可沿经线爬坡/顺着气流升，弧线绕赤道山谷，提笔用传送门/星桥。
- 镜头：跟在角色斜后方，略远、略慢；终点揭晓时拉到俯视/远景，整条足迹连成字母浮在星球表面或星空中。
- 手感仍要对标原神式摇杆：左浮动摇杆、右跳/滑翔/当前耳朵能力；推即走、松即停。

## 3. 能力 / 机关 / 敌人 / Boss（从 v6 迁移到球面）

- 五种耳朵：铃耳、伞耳、钻耳、弹耳、灯耳 — 行为语义不变，表现改为球面上的交互。
- 假岔路：看起来能走的小径，逆风/环流把你吹回主路径。
- 隐藏房间：星球背面或云下小洞。
- Boss：大雾怪占住字母最后一笔对应的山顶，摇铃散雾。
- 首关仍做 U：五段主题（森林丘、萤光洞、泉水庭、风车脊、云顶 Boss）环绕在同一颗「U 形峡谷」星球上。

## 4. 技术路线（已定：对齐 Sac，不用 Three.js）

用户否决了「原型优先 Three.js / WebGL」。工具链对齐 Sac《小王子：星辰之旅》（littleprince.dev / @Saccc_c）：概念参考 → Tripo / Blender 资产 → Unity 场景 + C# 玩法。Sac 的线上构建是**桌面 WebGPU**；本产品仍以**微信**为出货目标，因此两条目标并存，而不是把 3D 做进当前静态页。

- **观感原型（桌面）**：Unity 6，WebGPU 网页构建。用来对齐黄金时刻的光影、镜头和行走手感。工程不放在本仓库。
- **出货路径（微信小游戏）**：团结引擎 / Tuanjie 导出微信小游戏。用户已有另一项目的 Tuanjie 2022.x 微信构建，本项目沿用该导出，不再用 H5 Three.js 壳。
- **资产管线**：概念参考（团绒脸型 #4 等）→ Tripo 出模型 → Blender（CLI / Auto-Rig Pro）做地形、绑骨、清理 → Unity 6 或团结场景 + C#。黄金时刻仍是定向光、天空、轻雾、适度 bloom，放在引擎里做。
- **本仓库的边界**：GaoDaxiong/raoxianmao-proto 继续只托管现有 2D 横版（默认 v6.1）。不新增 Three.js、不新增 `?v=planet-0` 或 `planet/` 可玩页，也不把 Unity / 团结工程放进这个静态站。3D 工程另仓。
- **玩法不变**：主角仍是团绒（烟灰白毛球、浅蓝耳尖、大垂耳滑翔；不抄小王子）。路径拼字母的核心诡计保留。v1 仍是单星球、可走、可跳、按住滑翔、只记录足迹、假终点不揭晓字母。
- **性能**：微信包以中端手机约 30fps 为目标；控制星球规模，远景可用 billboard。桌面 WebGPU 预览可以更松，但不作为出货规格。
- **分享 `#c=`**：仍属于现有 2D H5。本次不把分享链迁进 Unity / 团结；v2 揭晓与 v3 多字母再定 3D 侧怎么接。

## 5. 迭代版本
