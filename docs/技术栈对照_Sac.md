## 和本仓库的关系

- `GaoDaxiong/raoxianmao-proto` 是 GitHub Pages 上的 2D H5。默认首页继续是 v6.1 横版。
- 不在这里加 Unity 工程、团结工程或可玩 3D 页。Unity / 团结项目另仓。
- 不合并到 `main`，直到用户验收可玩原型。

## 玩法范围（不因换引擎而改）

- 主角仍是团绒。耳朵滑翔等手感留在 C# 里做。
- 核心诡计仍是：玩家路径悄悄拼成字母；游玩时只见足迹，通关后才揭晓。
- **v1**：单星球、可走、可跳、按住滑翔、记录足迹、假终点不揭晓字母。
- v2 及以后（五区能力、Boss、揭晓 U、分享）仍按设计方案第 5 节，不在本次文档里提前实现。
