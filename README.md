# 南瓜灯小幽灵 H5 原型（原“绕线猫”）

公开地址（GitHub Pages）：https://gaodaxiong.github.io/raoxianmao-proto/

本地：`python3 -m http.server 8765` 后打开 http://127.0.0.1:8765/

玩法（v4）：横屏。左手浮动摇杆移动（桌面 WASD/方向键），靠近正在打转发光的小鬼火，按右下角按钮（桌面空格）把它收进队伍；离路线太远会越来越慢、灯线和蜡烛闪烁。三关（默认 I♥U）通关后倒带揭晓发光的字，可定制单词生成分享链接（#c= 格式与 v1/v2 相同）。

## v4（2026-10-12）横屏 + 原神式摇杆 + 迷路的小鬼火
- 强制横屏：竖握手机时整个舞台 CSS 旋转 90°，触摸坐标同步换算；首次点“开始”时尝试全屏 + screen.orientation.lock('landscape')。
- 浮动摇杆：左侧 45% 区域任意按下生成底座（死区 8%，半径 60px），模拟量速度（<60% 走、>60% 跑），约 0.1s 加速到满速、0.06s 停下，转向几乎即时；输入当帧生效，镜头带轻微延迟和前瞻。方向弧、旋钮高亮、角色倾斜、光点拖尾、安卓起步震动。多点触控：摇杆与按钮同时可用。
- 铃铛换成“迷路的小鬼火”：下一个正确的小鬼火绕圈发暖光，越近越亮、风铃越密；靠近时右下按钮亮起脉动，按下收集，它会排在小幽灵身后跟随，已收集部分的灯线略微变亮。诱饵小鬼火是蓝色、困倦，按了会打哈欠飘走；还没轮到的正确小鬼火会“还没轮到我~”地晃一下。仍按顺序校验检查点。
- 引导：下一个小鬼火在屏幕外时，屏幕边缘对应方向会有柔和光晕；原地卡住超过 8 秒，会有一只萤火虫从目标飞到你身边再飞回去。
- 偏离路线不再硬拽：越往外越慢（约 1.2 格处停住），往回走不受影响；灯线和蜡烛闪烁警告。
- 揭晓：收集到的小鬼火飞出来沿字母排开，把字点亮。
## v3（2026-10-12）主角换成南瓜灯小幽灵
- 主角：奶油色小幽灵，戴南瓜小帽（带藤蔓、叶子、小白花），双手提着发光的南瓜灯。全部 Canvas 程序化绘制（赛璐璐风），参考 gpt/ghost-1-5.png 的 2 号。
- 动画：漂浮上下、尾巴飘动/朝运动反方向拖、起步拉伸/停下压扁、向运动方向倾斜、眨眼、灯笼钟摆晃动+火光闪烁；铃铛响时开心脸、绷紧时担心脸、揭晓页睡着。
- 灯笼在草地上投下暖色光圈；尘土改为发光小光点，灯笼后面拖着橙色火星。
- 线改为“南瓜灯余烬线”：游戏中暗淡、松弛、烟琥珀色，旧的部分渐隐，看不出形状；接近长度上限会闪烁、冒火星。物理/缠绕/校验不变。
- 起点改为小南瓜蜡烛；左上角线量改为会变短的蜡烛；每笔结束“系好”时火星一闪；终点改为大南瓜灯。
- 揭晓：倒带 → 拉远 → 余烬重新点亮 → 绷直成橙金色发光字母（辉光+火星），木桩下沉，夜空。
