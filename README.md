# 南瓜灯小幽灵 H5 原型（原“绕线猫”）

公开地址（GitHub Pages）：https://gaodaxiong.github.io/raoxianmao-proto/

本地：`python3 -m http.server 8765` 后打开 http://127.0.0.1:8765/

玩法：拖动屏幕（或方向键）带小幽灵去找会晃、会响的金色铃铛；灯线不够会被拽回。三关（默认 I♥U）通关后倒带揭晓发光的字，可定制单词生成分享链接（#c= 格式与 v1/v2 相同）。

## v3（2026-10-12）主角换成南瓜灯小幽灵
- 主角：奶油色小幽灵，戴南瓜小帽（带藤蔓、叶子、小白花），双手提着发光的南瓜灯。全部 Canvas 程序化绘制（赛璐璐风），参考 gpt/ghost-1-5.png 的 2 号。
- 动画：漂浮上下、尾巴飘动/朝运动反方向拖、起步拉伸/停下压扁、向运动方向倾斜、眨眼、灯笼钟摆晃动+火光闪烁；铃铛响时开心脸、绷紧时担心脸、揭晓页睡着。
- 灯笼在草地上投下暖色光圈；尘土改为发光小光点，灯笼后面拖着橙色火星。
- 线改为“南瓜灯余烬线”：游戏中暗淡、松弛、烟琥珀色，旧的部分渐隐，看不出形状；接近长度上限会闪烁、冒火星。物理/缠绕/校验不变。
- 起点改为小南瓜蜡烛；左上角线量改为会变短的蜡烛；每笔结束“系好”时火星一闪；终点改为大南瓜灯。
- 揭晓：倒带 → 拉远 → 余烬重新点亮 → 绷直成橙金色发光字母（辉光+火星），木桩下沉，夜空。
